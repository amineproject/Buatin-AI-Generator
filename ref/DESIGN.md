## Brand & Style

This design system is tailored for Indonesian educators navigating modern curriculum standards like Kurikulum Merdeka and the Deep Learning (8-3-3-4) instructional framework. The brand embodies three core attributes:
- **Intelligent Empiricism:** Sophisticated, dependable AI assistance that eliminates administrative fatigue without de-skilling the educator.
- **Warm Authority:** Accessible, encouraging, and structurally sound—eschewing clinical coldness in favor of dignified civic utility.
- **Clarity of Purpose:** Uncluttered document visualization, structured pedagogical workflows (Capaian Pembelajaran, Alur Tujuan Pembelajaran, Modul Ajar, Lembar Kerja Peserta Didik), and effortless prompt generation.

The aesthetic fuses **Modern Corporate SaaS** with **Refined Editorial Utilitarianism**. Layouts utilize immaculate whitespace, crisp slate borders, ambient indigo-tinted elevation, and structured metadata badges to create an intuitive workspace that inspires teacher confidence and speeds up pedagogical production.

## Colors

The palette establishes an authoritative, highly readable, and fatigue-reducing environment for long curriculum generation sessions:

- **Primary (`#3B52DF` - Smart Indigo):** Anchor color used for primary CTAs, active navigation items, progress milestones, and active selection outlines. It projects technological precision and institutional credibility.
- **Secondary (`#0D9488` - Vibrant Teal):** Used for verified pedagogical alignments (e.g., Kurikulum Merdeka verified badges), success states, completed modular stages, and LKPD download triggers.
- **Tertiary (`#F59E0B` - Warm Amber):** Reserved specifically for AI features, generation sparkles, automated suggestions, prompt enhancement indicators, and Deep Learning 8-3-3-4 focus callouts.
- **Neutral Palette:**
  - Base Canvas: `#F8FAFC` (Slate 50) for canvas softness.
  - Surface Pure: `#FFFFFF` for primary container cards and document preview papers.
  - Subdued Surface: `#F1F5F9` (Slate 100) for nested input containers, metadata sidebars, and inactive tab tracks.
  - Border & Dividers: `#E2E8F0` (Slate 200) for ultra-clean structural boundaries.
  - Text Primary: `#0F172A` (Slate 900) providing AA/AAA compliant typographic contrast.
  - Text Secondary: `#475569` (Slate 600) for metadata labels and prompt notes.
  - Text Muted: `#94A3B8` (Slate 400) for placeholder texts and trailing shortcuts.

## Typography

Typography focuses on immediate scannability and high reading comfort across Indonesian educational verbiage:
- **Headings & Body (`Plus Jakarta Sans`):** Warm geometric forms offer approachable modernity with solid structural balance, crucial for long form materials such as Modul Ajar rationale, Capaian Pembelajaran, and rubrics.
- **Labels & UI Metadata (`Inter`):** Systematic neutral metrics used across table matrices, parameter tags, phase indicators (Fase A-F), and action toolbars for crisp legibility at small sizes.
- **Rhythm & Accessibility:** Headings feature gentle negative tracking to tighten display layouts, while long-form content maintains generous line heights (1.5–1.6x) to allow effortless proofreading.

## Layout & Spacing

The platform uses a balanced fluid grid system based on an 8-point spatial cadence:
- **Desktop (1024px+):** 12-column layout with `2rem` outer margin and `1.5rem` gutters. Configured primarily as a split-screen workbench: a 5-column left generation console paired with a 7-column real-time document previewer.
- **Tablet (768px – 1023px):** 8-column layout with `1.5rem` margins and `1rem` gutters. The previewer slides underneath or toggles via persistent tab switcher.
- **Mobile (< 768px):** Single-column stacked layout with `1rem` margins and `1rem` gutters. Form factor switches to full-width steps with a floating preview sheet trigger.
- **Internal Spacing:** Component internal padding strictly follows `space-xs` (4px) for pill tags, `space-sm` (8px) for buttons and inputs, `space-md` (16px) for module sections, `space-lg` (24px) for card bodies, and `space-xl` (32px) for major workspace separation.

## Elevation & Depth

Visual hierarchy uses a refined hybrid of **low-contrast borders** and **ambient indigo-tinted elevation**:

- **Layer 0 (Canvas Base):** Flat `#F8FAFC` background.
- **Layer 1 (Card & Section Surfaces):** Pure `#FFFFFF` surface with a crisp 1px border (`#E2E8F0`) and subtle floor shadow: `0px 1px 3px rgba(15, 23, 42, 0.04), 0px 1px 2px rgba(15, 23, 42, 0.02)`.
- **Layer 2 (Floating Action Bars & Interactive Modals):** Crisp 1px border (`#E2E8F0`) paired with deep ambient elevation: `0px 10px 15px -3px rgba(59, 82, 223, 0.07), 0px 4px 6px -4px rgba(15, 23, 42, 0.05)`.
- **Layer 3 (Active Document Page Sheet):** Visual simulation of physical A4 print paper inside the preview viewport: `0px 4px 20px -2px rgba(15, 23, 42, 0.08)`, elevated above the workspace track.
- **AI Highlight Elevation:** Generation states and active sparkle triggers project an ambient tertiary aura: `0px 0px 16px -2px rgba(245, 158, 11, 0.18)`.

## Shapes

The geometric framework adheres to **Level 2 (Rounded)**:
- **Base Components (Inputs, Buttons, Dropdowns):** `0.5rem` (8px) corner radius, delivering a clean, friendly, yet professional touchpoint.
- **Cards, Document Containers, Tab Panels:** `1rem` (16px) corner radius, establishing modern structural envelopes.
- **Modal Dialogs & Large Preview Canvases:** `1.5rem` (24px) corner radius.
- **Status Pills, Fase Tags & AI Indicators:** Fully rounded pill shapes (`9999px`) to immediately contrast with rectangular content matrices.

## Components

### Buttons
- **Primary:** Solid `#3B52DF` background, white text, 8px radius, subtle hover shift to `#2D41C6`.
- **Secondary / Action:** Outlined 1px `#E2E8F0` on white, `#0F172A` text, hover with `#F8FAFC`.
- **AI Generation CTA:** Subtle gradient (`#3B52DF` to `#4338CA`) with an amber sparkle icon (`#F59E0B`), projecting generative intelligence.
- **Icon Actions:** 36x36px utility buttons for quick actions: Copy, Export PDF, Regenerate, Edit.

### Chips & Framework Badges
- **Kurikulum Merdeka Badge:** Pill shape, `#ECFDF5` background, `#0D9488` text, and border `rgba(13, 148, 136, 0.2)`.
- **Deep Learning (8-3-3-4) Badge:** Pill shape, `#FFFBEB` background, `#D97706` text, with a micro amber indicator dot.
- **Phase Tags (e.g., Fase A, Fase D):** Pill shape, `#EEF2FF` background, `#3B52DF` text, Inter Semibold 11px uppercase.

### Input Fields & Selectors
- **Form Controls:** 44px standard touch targets, `#FFFFFF` background, `#E2E8F0` border, `#0F172A` text.
- **Focus State:** 2px ring in `rgba(59, 82, 223, 0.25)` with a solid `#3B52DF` border.
- **Prompt Textarea:** Expandable text box with embedded parameter chips (e.g., Target Murid, Alokasi Waktu, Model Pembelajaran) pinned directly below the text canvas.

### Checkboxes & Radio Controls
- Rounded 6px checkbox square / circular radio with a `#CBD5E1` border.
- Active state transitions smoothly to solid `#3B52DF` with crisp white checkmark iconography.

### Cards & Document Previews
- **Form Input Card:** Pure white, 16px corner radius, `#E2E8F0` border, partitioned with subtle slate header bars.
- **Rich Document Previewer:** Emulates an authentic document canvas. Features a top sticky toolbar containing segmented preview tabs (Rangkuman, Detail CP/TP, Modul Lengkap, LKPD, Rubrik), zoom controls, an "Export Word/PDF" dropdown, and an instant "Salin Prompt / Konten" button with animated checkmark feedback.
